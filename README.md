# Street-Light-Project

## 📌 Project Description

The Smart Street Light Project is an automatic street light control system using an LDR (Light Dependent Resistor) sensor. The system automatically turns the street lights ON during darkness and turns them OFF during daylight.

This project helps to save electrical energy and reduces manual effort.

## 🎯 Objectives

- To automatically control street lights
- To save electrical energy
- To reduce manual operation
- To develop a simple and efficient smart lighting system

## ⚙️ Components Required

- Arduino Uno
- LDR Sensor
- LED / Street Light
- Resistor
- Breadboard
- Jumper Wires
- Power Supply

## 🔧 Working Principle

The LDR sensor detects the intensity of surrounding light.

- During **daytime**, the light intensity is high, so the street light remains **OFF**.
- During **nighttime**, the light intensity is low, so the street light automatically turns **ON**.

## 💡 Features

- Automatic ON/OFF operation
- Energy saving
- Low cost
- Easy to implement
- Reduces manual effort
